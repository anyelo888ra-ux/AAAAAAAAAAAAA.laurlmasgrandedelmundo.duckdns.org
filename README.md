# 💀 La URL más larga del mundo

Proyecto experimental de GitHub Pages sobre URLs absurdamente largas, páginas de estados HTTP y simulaciones web.

🌐 **Sitio:** https://anyelo888ra-ux.github.io/AAAAAAAAAAAAA.laurlmasgrandedelmundo.estaeslaurlmaslargaquepuedescrearcongithubpageslong.duckdns.org/

## 🚀 Secciones

- **[Generador principal](./index.html):** crea URLs con segmentos repetidos `AAAAAAAAAAAAA.html/`, estima su longitud y permite descargar/copiar el texto cuando el navegador lo permite.
- **[Windows 10.exe — simulador de caos seguro](./windows10.html):** escritorio ficticio, navegador local de mentira, notificaciones, errores visuales, pantalla azul, apagado/reinicio y formateo simulados.
- **[Páginas HTTP](#museo-de-estados-http):** páginas informativas para aprender sobre códigos de estado.
- **[Rutas anidadas](./AAAAAAAAAAAAA.html/):** niveles que existen físicamente en el repositorio.

## 🧪 Museo de estados HTTP

Los estados HTTP se agrupan en cinco familias:

| Familia | Significado |
| --- | --- |
| **1xx** | Respuestas informativas |
| **2xx** | Solicitudes satisfactorias |
| **3xx** | Redirecciones |
| **4xx** | Errores del cliente |
| **5xx** | Errores del servidor |

Páginas disponibles:

- [100 — Continue](./100.html), [101 — Switching Protocols](./101.html), [102 — Processing](./102.html), [103 — Early Hints](./103.html), [104 — página experimental](./104.html)
- [200 — OK](./200.html), [201 — Created](./201.html), [202 — Accepted](./202.html), [203 — Non-Authoritative Information](./203.html), [204 — No Content](./204.html)
- [400 — Bad Request](./400.html)
- [401 — Unauthorized](./401.html)
- [403 — Forbidden](./403.html)
- [404 — Not Found](./404.html)
- [414 — URI Too Long](./414.html)

No todos los números entre 100 y 599 están asignados, y algunas páginas de este proyecto son ejemplos educativos, no implementaciones del comportamiento del servidor.

## 🪟 Sobre Windows 10.exe

El simulador es una broma visual ejecutada en la página. El navegador no navega a internet de verdad, y las carpetas, procesos, alertas, errores, apagado, reinicio y formateo son ficticios. No instala software, no descarga malware, no accede a tus archivos ni modifica Windows. Puedes salir cerrando la pestaña o volviendo al proyecto.

## ⚠️ Límites importantes

- El generador crea una dirección como texto; **no crea automáticamente carpetas o rutas** en GitHub Pages.
- Las páginas `400.html`, `404.html`, `414.html` y otras son páginas informativas; abrirlas no hace que el servidor devuelva ese código HTTP real.
- Una URL demasiado larga puede ser rechazada con `414 Request-URI Too Large` u otro error. Los límites dependen del navegador, servidor y red.
- El simulador Windows es solo visual. No intenta apagar ni formatear el ordenador real.
